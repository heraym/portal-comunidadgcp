Tengo un grupo que llamamos Comunidad GCP donde los miembros son multiples arquitectos y tecnicos de distintas empresas que usan Google Cloud. En el grupo realizamos charlas periodicas y eventos presenciales, ademas de distintas novedades de productos.
Necesito crear una aplicacion web donde pueda administrar este grupo.
La aplicacion tiene que darme la posibilidad de que :
- Un usuario no registrado vea de que se trata el grupo.
- Un usuario se registre con su cuenta de gmail
La aplicacion tiene que darme la posibilidad de que un usuario registrado :
- Vea que charlas hay pendientes, que dia, que hora y cual es el ID de Meet.
- Vea que charlas se hicieron ya y pueda acceder a la grabacion.
- Haya una seccion donde se carguen noticias en general de GCP
- Haya una seccion donde se cargue un documento periodicamente a modo Newsletter de novedades en GCP
- Haya una seccion donde se anuncien eventos presenciales y este el nombre, fecha, lugar y link para registrarse
- Haya una seccion donde los usuarios registrados puedan hacer preguntas, comentarios,etc. 

Ademas, la aplicacion tiene que tener una parte de Administracion donde un usuario admin pueda:
- Cargar charlas periodicas y sus grabaciones
- Cargar Newsletters
- Cargar noticias en general
- Cargar eventos presenciales
- Administrar usuarios 
- Ver comentarios/preguntas y contestarlos

Quiero que ejecutes las siguientes tareas:
- Definir un plan y armar un documento con la descripcion del plan
- Hacer un disenio general de la aplicacion usando el MCP de Stitch.
- Desarrollar la aplicacion que tiene que correr en Google Cloud usando Cloud Run, Firebase para la autenticacion y Firestore para los datos de base de datos.
